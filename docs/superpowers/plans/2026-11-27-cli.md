# Interactive CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run one task, see the model's progress and give informed approvals in the same terminal.

**Architecture:** The CLI observes committed run states and renders new messages. Runtime remains the authority for all approvals, evidence and side effects. Run discovery reads summaries from the existing SQLite data.

**Tech Stack:** TypeScript, Node.js 22.13+, readline, node:sqlite, node:test, POSIX launcher.

**Spec:** User request in this session plus existing CLI, planning, policy and recovery contracts in [docs/spec.md](../../spec.md).

## Global Constraints

Preserve existing single-step commands, database format, safe-mode defaults and noninteractive automation. Do not send model requests for history, status, help or trace. Work with existing databases and custom storage paths.
